安装指南

macOS

  1. 推荐：在终端中运行上方的一行命令 —— 安装到“应用程序”，没有 Gatekeeper 提示。再次运行即可更新。
  2. 或下载上方的 .dmg（Apple Silicon），打开并把 Git Light 拖入 应用程序。
  3. 启动应用 —— 之后随时可通过 Git Light → 检查更新… 保持最新。
macOS 提示“移到废纸篓”或拒绝打开？

浏览器会给下载的文件添加隔离标记，而 macOS 会阻止没有 Apple Developer ID 的应用。你的下载并没有问题：

最简单的解决办法：改用一行安装命令 —— 它的下载会完全跳过隔离标记。如果你已经从 .dmg 安装，请在终端中运行一次：

codesign --force --deep --sign - "/Applications/Git Light.app"
xattr -dr com.apple.quarantine "/Applications/Git Light.app"

Windows

  1. 下载上方的 .exe 安装程序。
  2. 运行并按照安装向导操作。
  3. 从开始菜单启动 —— 之后随时可通过 Git Light → 检查更新… 保持最新。

Linux

  1. 下载上方的 .AppImage 或 .deb。
  2. AppImage：用 chmod +x *.AppImage 使其可执行后运行。Deb：使用 sudo apt install ./git-light_*.deb 安装。
  3. 启动应用 —— 之后随时可通过 Git Light → 检查更新… 保持最新。

常见问题

常见问题解答

关于 Git Light 的快速解答。

Git Light 真的免费吗？

是的。采用 MIT 许可证，没有付费版本、没有试用期、没有广告，也没有功能限制。本页列出的所有功能都可在免费版本中使用。

需要 GitHub、GitLab 或 Bitbucket 账号吗？

不需要。没有登录、没有许可证密钥，也没有遥测。Git Light 可用于磁盘上的任何仓库，以及你自己的 Git 已配置好的任何远程仓库，支持 HTTPS 或 SSH。

可以离线使用吗？

可以。浏览历史、提交图、暂存、差异、提交、分支、合并、变基和贮藏都是本地操作。只有 fetch、pull、push 和 clone 需要网络。

它自带 Git 吗？

不 —— 它运行系统中的 git 二进制文件，因此你现有的配置、别名、凭据助手、SSH 密钥、钩子以及 .gitignore 行为都保持不变。

可以使用我现有的仓库吗？

可以。打开任何包含 .git 目录的文件夹（或克隆/初始化一个新仓库）。Git Light 不会添加专有索引，也不会向你的仓库写入额外文件。

支持 Apple Silicon 和 Intel Mac 吗？

完全支持 Apple Silicon（arm64）。当前构建不支持 Intel Mac —— 发布流程只生成 aarch64 的 .dmg。同时也提供 Windows x64 和 Linux x86_64 版本。

macOS 提示应用已损坏或将其移到废纸篓。

这是 Gatekeeper 对临时签名的反应，并非下载损坏 —— 请参阅 macOS 安装说明。

支持哪些语言？

英语、葡萄牙语（巴西）、简体中文、西班牙语、法语、德语和日语。界面会跟随操作系统语言，也可在设置中切换。本站同样提供这七种语言。

Guia de instalação

macOS

  1. Recomendado: execute o comando de uma linha acima no Terminal — instala em Aplicativos sem avisos do Gatekeeper. Execute de novo para atualizar.
  2. Ou baixe o .dmg acima (Apple Silicon), abra e arraste o Git Light para Aplicativos.
  3. Abra o app — e use Git Light → Verificar atualizações… quando quiser para ficar em dia.
O macOS diz "mover para o Lixo" ou se recusa a abrir?

Navegadores adicionam uma marca de quarentena aos arquivos baixados, e o macOS bloqueia apps sem um Apple Developer ID. Não há nada errado com o seu download:

Correção mais fácil: use o comando de instalação de uma linha — os downloads dele pulam a quarentena. Se você já instalou pelo .dmg, execute uma vez no Terminal:

codesign --force --deep --sign - "/Applications/Git Light.app"
xattr -dr com.apple.quarantine "/Applications/Git Light.app"

Windows

  1. Baixe o instalador .exe acima.
  2. Execute e siga o assistente de instalação.
  3. Abra pelo menu Iniciar — e use Git Light → Verificar atualizações… quando quiser para ficar em dia.

Linux

  1. Baixe o .AppImage ou o .deb acima.
  2. AppImage: torne executável com chmod +x *.AppImage e execute. Deb: instale com sudo apt install ./git-light_*.deb.
  3. Abra o app — e use Git Light → Verificar atualizações… quando quiser para ficar em dia.

FAQ

Perguntas frequentes

Respostas rápidas sobre o Git Light.

O Git Light é realmente gratuito?

Sim. Licença MIT, sem plano pago, sem período de teste, sem anúncios e sem recursos bloqueados. Todos os recursos listados nesta página estão disponíveis na versão gratuita.

Preciso de uma conta no GitHub, GitLab ou Bitbucket?

Não. Não há login, chave de licença nem telemetria. O Git Light funciona com qualquer repositório no disco e com qualquer remoto que o seu próprio Git já esteja configurado para usar, via HTTPS ou SSH.

Funciona offline?

Sim. Navegar pelo histórico, o grafo de commits, o staging, os diffs, os commits, os branches, os merges, os rebases e os stashes são operações locais. Apenas fetch, pull, push e clone precisam de rede.

Ele vem com o seu próprio Git?

Não — ele executa o binário git do sistema, então sua configuração, apelidos, credential helper, chaves SSH, hooks e o comportamento do .gitignore continuam valendo sem alterações.

Posso usar meus repositórios existentes?

Sim. Abra qualquer pasta que contenha um diretório .git (ou clone/inicie um novo). O Git Light não adiciona nenhum índice proprietário e não grava arquivos extras no seu repositório.

Funciona em Macs Apple Silicon e Intel?

Apple Silicon (arm64) é totalmente suportado. Macs Intel não são suportados pelas builds atuais — o pipeline de release só gera um .dmg aarch64. Também há builds para Windows x64 e Linux x86_64.

O macOS diz que o app está danificado ou o move para o Lixo.

Isso é o Gatekeeper reagindo a uma assinatura ad-hoc, não um download corrompido — veja a nota de instalação para macOS.

Quais idiomas são suportados?

Inglês, português (Brasil), chinês simplificado, espanhol, francês, alemão e japonês. A interface segue o idioma do sistema e pode ser alterada nas Configurações. Este site está disponível nos mesmos sete idiomas.

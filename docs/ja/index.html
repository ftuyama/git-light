アプリを入手

Git Light をダウンロード

macOS、Windows、Linux 向けの無料デスクトップアプリ —— オープンソース、アカウント不要。

curl -fsSL https://raw.githubusercontent.com/ftuyama/git-light/main/scripts/install.sh | sh
1 つのコマンドで簡単インストール —— Gatekeeper の警告なし。
macOS 版をダウンロード .dmg · Apple Silicon Windows 版をダウンロード .exe インストーラー Linux 版をダウンロード .AppImage · .deb
インストールガイド

macOS

  1. 推奨：上の 1 行コマンドをターミナルで実行します —— Gatekeeper の警告なしでアプリケーションにインストールされます。再実行すると更新できます。
  2. または上の .dmg（Apple Silicon）をダウンロードし、開いて Git Light をアプリケーションにドラッグします。
  3. アプリを起動 —— その後は Git Light → アップデートを確認… でいつでも最新にできます。
macOS が「ゴミ箱に入れる」と表示したり、開けない場合

ブラウザーはダウンロードしたファイルに隔離フラグを付け、macOS は Apple Developer ID のないアプリをブロックします。ダウンロード自体に問題はありません：

最も簡単な解決策：代わりに 1 行のインストールコマンドを使ってください —— そのダウンロードは隔離フラグを完全に回避します。すでに .dmg からインストールした場合は、ターミナルで一度実行します：

codesign --force --deep --sign - "/Applications/Git Light.app"
xattr -dr com.apple.quarantine "/Applications/Git Light.app"

Windows

  1. 上の .exe インストーラーをダウンロードします。
  2. 実行してセットアップウィザードに従います。
  3. スタートメニューから起動 —— その後は Git Light → アップデートを確認… で最新にできます。

Linux

  1. 上の .AppImage または .deb をダウンロードします。
  2. AppImage：chmod +x *.AppImage で実行可能にして起動します。Deb：sudo apt install ./git-light_*.deb でインストールします。
  3. アプリを起動 —— その後は Git Light → アップデートを確認… で最新にできます。

FAQ

よくある質問

Git Light についての簡単な回答。

Git Light は本当に無料ですか？

はい。MIT ライセンスで、有料プラン、試用期間、広告、機能制限はありません。このページに載っているすべての機能が無料版で利用できます。

GitHub、GitLab、Bitbucket のアカウントは必要ですか？

いいえ。サインイン、ライセンスキー、テレメトリーはありません。Git Light はディスク上の任意のリポジトリ、およびお使いの Git が設定済みの任意のリモート（HTTPS または SSH）で動作します。

オフラインでも使えますか？

はい。履歴の閲覧、コミットグラフ、ステージング、差分、コミット、ブランチ、マージ、リベース、スタッシュはすべてローカル操作です。ネットワークが必要なのは fetch、pull、push、clone のみです。

Git は同梱されていますか？

いいえ —— システムの git バイナリを実行するため、既存の設定、エイリアス、credential helper、SSH キー、フック、.gitignore の動作がそのまま適用されます。

既存のリポジトリを使えますか？

はい。.git ディレクトリを含むフォルダーを開く（またはクローン/初期化する）だけです。Git Light は独自のインデックスを追加せず、リポジトリに余分なファイルも書き込みません。

Apple Silicon と Intel Mac で動作しますか？

Apple Silicon（arm64）は完全にサポートされています。Intel Mac は現在のビルドではサポートされていません —— リリースパイプラインは aarch64 の .dmg のみを生成します。Windows x64 と Linux x86_64 のビルドも利用できます。

macOS がアプリの破損を報告したり、ゴミ箱に移動したりします。

これはアドホック署名に対する Gatekeeper の反応であり、ダウンロードの破損ではありません —— macOS のインストール手順を参照してください。

対応している言語は？

英語、ポルトガル語（ブラジル）、簡体字中国語、スペイン語、フランス語、ドイツ語、日本語です。UI は OS の言語に従い、設定で切り替えられます。このサイトも同じ 7 言語で利用できます。
